Sistema de Gestión Hotelera - TP1 BDD

## Instrucciones de Instalación y Uso

1. **Base de Datos:**
   - Abrir SQL Server Management Studio.
   - Ejecutar en orden los scripts ubicados en la carpeta `Scrips/`.

2. **Backend (API C#):**
   - Abrir la terminal en la carpeta `SistemaHotelApp/HotelBackend`.
   - Ejecutar el comando `dotnet run`.

3. **Frontend:**
   - Abrir el archivo `SistemaHotelApp/Frontend/index.html` en cualquier navegador web.
